# User Flow & Information Architecture

## Main
Dashboard, Kasir, Transaksi, Produk, Stok, Pembelian, Keuangan, Pelanggan, Laporan, Pengaturan.

## Sale
POS → Search/Scan/Manual → Cart → Checkout → Payment → Complete → Stock/Cash → Receipt.

## Purchase
Supplier → Purchase → Items → Receive → Stock IN → Payment/Debt.

## Return
Transaction → Item → Quantity → Condition → Refund → Stock → Complete.

## Owner monitoring
Dashboard → Sales → Profit → Cash → Low Stock → Supplier Debt → Reports.

## UX
Large readable text, clear buttons, minimal clicks, Indonesian language, responsive desktop/tablet/mobile, barcode optional.
